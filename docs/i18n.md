# Languages

The site speaks English, Spanish and German. English is the canonical language
and lives at the root; every other language lives under its own prefix (`/es`,
`/de`). The root is the one address that negotiates: it reads the browser's
`Accept-Language`, or the `locale` cookie a reader set with the footer switcher,
and redirects to the matching prefix. Every other URL states its language and
is never redirected.

Everything language-shaped hangs off `LOCALES` in `src/i18n/index.ts`: path
prefixes, `hreflang`, the sitemap, the Markdown pages, the footer switcher and
the middleware's negotiation all read it, so none of them names a language.

## Where the words live

- **Interface copy:** one file per language in `src/i18n/` (`en.ts`, `es.ts`,
  `de.ts`), each typed as `LocaleCopy` from `types.ts`, so a missing string is a
  type error rather than a blank on the page.
- **Project descriptions and stories:** the `projects` table in the `oliweb` D1
  database, one pair of columns per language (`short_description_xx`,
  `history_xx`). The site reads the requested language and falls back to
  English, then to any other language that has the text, so a project written
  in one language still shows everywhere. The admin panel edits these columns.

## Adding a language

1. Add the code to `LOCALES`, a name to `LOCALE_NAMES` and a region to
   `OPEN_GRAPH_LOCALES` in `src/i18n/index.ts`, and register its copy in
   `copies`. The type checker then lists everything that is still missing.
2. Write `src/i18n/xx.ts` (copy `en.ts` and translate it). Check the headings in
   the narrow rail and the mobile header: some languages run longer than English.
3. Add a migration with the two new columns (see `0007_add_german_project_copy.sql`)
   and apply it to production **before** deploying: the site selects them, so
   a deploy that runs ahead of its migration breaks every project page.
4. Add the two fields to the admin panel's project form and column list.
5. Update the fixtures in `tests/fixtures/projects.sql` and the language tests.
