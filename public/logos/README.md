# Brand marks

Every logo the stack page shows, taken from its owner rather than drawn here.
The files are normalised only in the ways an `<img>` at 24px needs: the
`<title>` and the intrinsic width and height are dropped so the element sizes
them, and nothing else about the geometry is touched.

- Seventeen come from **simple-icons** (CC0-1.0), which publishes each mark as
  one path on a 24x24 grid together with its owner's colour. The colour is
  written onto the `<svg>` here so the file carries it.
- **playwright.svg** — playwright.dev.
- **vs-code.svg**, **wsl.svg** — Microsoft's own application icons, via
  Wikimedia Commons.
- **codex.svg** — OpenAI's 2025 symbol, via Wikimedia Commons.

Three marks are black where they are drawn — Next.js, GitHub and OpenAI's
symbol — and their owners publish a white version for a dark ground, which is
the only ground this site has. Those three carry `#F2F2F2` instead of their
listed colour; every other file keeps the colour its owner gives it.

The marks are trademarks of their respective owners and are used here only to
name the tool they stand for.
